# 💬 SocketChat
SocketChat is a lightweight CLI program that allows you to create servers and have users join and chat with you!
You can start by creating a public server with your friends being able to join you through a seperate running program.

## Additional
This socket-to-socket connection uses TCP for it's connection and TLS for it's encyption and handling.

---

## Stack
- Java
- Sockets
- TCP
- TLS
- Docker
